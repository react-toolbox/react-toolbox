# React Toolbox 3.0.0-next.0

This is the first source-distributed preview of the modern React Toolbox. It preserves the original Material Design visual language while replacing the old React and styling infrastructure.

- React 19 and TypeScript source, installed through the shadcn registry. No runtime dependency on a published `react-toolbox` package.
- Material components live under the consumer's configured UI alias in `material/<component>/`. Existing shadcn components can coexist alongside them.
- Tailwind CSS 4 classes, original Material colors, typography and geometry, local fonts, and a CSS variable theme.
- Foundation dependencies are installed only when their component families need them.
- Copied source is owned by the application. Updates offer file overwrite prompts; use Git to review and merge customizations.
- Generated API documentation covers all 29 component families, including props, defaults, callbacks, and controlled state.
- OS reduced-motion preferences remove decorative motion while preserving progress semantics and overlay behavior.
- Picker defaults have stronger text contrast and larger year/AM/PM targets. These reviewed accessibility corrections preserve the surrounding Material 1 layout and palette.
- Tagged releases include reproducible source snapshots with checksums and dependencies pinned to the same release.

This preview changes the source installation layout. If you installed an earlier development registry, commit your application first, install the components again, and update any direct internal imports to `material/foundations/…`. Keep public imports such as `@/components/ui/material/button`. The shadcn CLI does not remove obsolete files: remove the old `react-toolbox/` implementation directory and old `material/<component>.tsx` wrappers only after confirming that nothing imports them. The new family entry is `material/<component>/index.ts`.

Link and Navigation wrappers are removed. Use your router's links and application navigation.

This major release removes the remaining duplicate compatibility APIs:

- Component `theme` and `classNames` maps and their slot types are removed. Customize components and compound parts with `className`, use CSS variables for shared styling, or edit installed source.
- Checkbox, RadioButton and Switch apply `style` and `className` to their root label. Their native input attributes and events keep targeting the underlying input.
- Replace legacy Toolbox `--color-*` keys and `var()` references with `--rt-color-*`, for example `--color-primary` → `--rt-color-primary`. `ThemeProvider` still scopes CSS variables and carries them through portals, but no longer rewrites old aliases.
- Replace `active` on `Menu`, `IconMenu`, `DatePicker`, and `TimePicker` with `open`/`onOpenChange` for controlled visibility or `defaultOpen` for initial internal visibility. Update the controlled value when `onOpenChange` fires. `Dialog`, `Drawer`, `Snackbar`, and `Overlay` keep their primary `active` API.
- Replace the internal workspace import `react-toolbox/ThemeProvider` with `react-toolbox/theme`. Registry consumers continue to import from their installed `material/theme` entry.
- Replace `Ripple`/`rippleFactory` with `useRipple`, and `Tooltip`/`tooltipFactory` with compound Tooltip parts or `useTooltip`. The decorator exports and their options are removed.
- Replace Tabs `index`/`defaultIndex`/`onChange` with string `value`/`defaultValue`/`onValueChange`, and give each `Tab` and explicit `TabContent` its own matching value. Tabs refs now expose the root DOM element.
- Enable Table selection with `selectionMode="single"` or `"multiple"` and give each selectable row a stable string `value`. Use `selected`/`defaultSelected` and `onSelectionChange` with those values; selection defaults to `"none"`. Numeric row selection and cell position callbacks are removed; `TableCell.onClick` receives the native React event.
- DatePicker values are `Date | null`; use `inputFormat` for custom display and submission text.
- Use the native React `readOnly` prop on DatePicker and TimePicker; the lowercase `readonly` prop is removed.
- Remove the ignored Button/BrowseButton `flat` props. Buttons retain their default flat appearance.
- Layout, Panel, NavDrawer, and Sidebar are removed. Compose responsive application navigation with AppBar, Drawer, and Tailwind.
- Picker transitions no longer install `react-transition-group` or expose its enter/exit class slots. They use the shared motion foundation, preserving themed lifetimes and reduced motion.
- Obsolete `/components`, `/docs/recipes`, Link and Navigation redirects and the deprecated-alias display are removed from the documentation site.
- Keyboard event simulations should set `key`; numeric-only `which` fallbacks are removed.

This is a prerelease. Automated visual, keyboard, and axe checks cover Chromium and WebKit, but manual screen-reader, high-contrast, and zoom checks are still outstanding; see `docs/accessibility.md`. Review changes and run your application's interaction, accessibility and visual checks before updating production source.
